# 卧推增力计划 Web 页面设计文档

**日期：** 2026-02-26
**项目：** benchpress

---

## 概述

一个公开部署的静态 Web 页面，用户输入卧推最大重量（1RM），自动推导出 4 个训练级别的各组重量，并支持一键保存为图片。

---

## 架构

**技术栈：** 纯静态 HTML + CSS + JavaScript，无框架，无后端
**依赖：** `html2canvas`（CDN 引入，用于截图保存）
**部署：** GitHub Pages

**文件结构：**
```
benchpress/
├── index.html        # 全部逻辑 + 样式
└── README.md
```

## UI 设计

**布局：**
- 顶部：标题 + 最大重量输入框 + 计算按钮
- 中部：4 张训练卡片（桌面横排，移动端 2×2）
- 底部：保存图片按钮

**风格：** 深色健身风格（深灰背景 + 橙色/黄色强调色），卡片式布局

---

## 交互逻辑

- 输入框默认值 `95`，按回车或点击"计算"触发更新
- 重量格式：保留1位小数，整数时省略小数点（如 `85 kg` 而非 `85.0 kg`）
- 保存图片：截取4张卡片区域，文件名格式 `benchpress-{maxWeight}kg.png`
- 保存过程中按钮变为"保存中..."防止重复点击

---

## 不在范围内

- 用户账号 / 登录
- 历史记录保存
- 重量取整到 2.5kg 倍数
